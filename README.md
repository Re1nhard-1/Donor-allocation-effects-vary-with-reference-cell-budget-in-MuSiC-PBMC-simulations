# Donor-allocation effects vary with reference-cell budget in MuSiC PBMC simulations

Code and results accompanying the [manuscript](https://doi.org/10.21203/rs.3.rs-11156252/v1) by Yunhao Jiang.

- **Code:** `analysis/` and `reproduction_integrated/`.
- **Results and figure source data:** `results/`.
- **Software versions:** `environment/`.

Study-generated simulated mixtures, known proportions and sampling designs are in [Zenodo](https://doi.org/10.5281/zenodo.23012998) (`data.zip`). Public reference datasets are obtained from their original providers; see [SOURCES.md](SOURCES.md). They are not redistributed in this data release.

See [run_commands.md](run_commands.md) for analysis entry points. The results include the PBMC, pancreas, component-intervention and measured-bulk analyses, including comparisons that did not support transfer of the PBMC trend.
